# SuperAgentPlusCloud

把项目当成一棵树来维护：严格控制主干，放手让枝叶生长。

这套设计要解决的不是"任务没人做"，而是：**项目持续推进时，当前有效的决定、依据和影响范围能否被唯一、可追溯地保留下来。**

## 核心流程

```text
提出需求 → 评估影响 → 被授权者确认 → 拆解任务 → Client 认领执行
        → 提交 Git 与证据 → 评审 → （若主干变更）记录并处置影响
```
