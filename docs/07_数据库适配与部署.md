# 07｜数据库适配与部署形态

> 回答两个问题：Center 要不要全部配置好才能启动；SQLite 之后要不要支持 MySQL / PostgreSQL。
> 标记：【判断】我的设计选择，可以推翻。

## 1. 启动门槛

**结论：不需要全部配置。** Center 的设计目标是「壳起来就能用」：

| 配置 | 是否必需 | 缺省行为 |
|---|---|---|
| 端口 / 监听地址 | 否 | `8787` / `127.0.0.1` |
| 数据库 | 否 | SQLite 文件 `center/data/center.db`，首次启动自动建表 |
| 模型（LLM） | 否 | 未配置时 `/sap-cloud/api/ai/*` 返回 503 `AI_NOT_CONFIGURED`，**核心链照常可用** |
| Web 面板产物 | 否 | 未构建时 `/` 返回提示页，API 不受影响 |

需要「初始化」的只有两类情况：换数据库、换模型。这类配置通过 Web 设置页完成（T10），配置落在 `center/config.json`（不入库）。

【判断】不要把「首次启动必须填一堆字段」当默认。ownCloud 那种向导适合**有明确管理员**的场景；而这个系统的第一批用户是开发团队，零配置能跑起来比配置项齐全更重要。

## 2. 配置分层

```
内置默认值  <  center/config.json  <  环境变量
```

环境变量仍然最高优先级，便于临时覆盖与测试。配置文件由设置页写入，可版本化排除（已在 `.gitignore`）。

## 3. SQLite 之后：MySQL / PostgreSQL

### 3.1 结论

**应该支持，但不是现在。** 判断依据：

- SQLite 适合单节点、小团队、内网部署——这正是当前目标场景；
- 多用户并发写、跨机部署、已有数据库运维体系时，PostgreSQL 是更稳的选择；
- MySQL 在国内存量环境里更常见，作为第二选项；
- 现在引入驱动会让 Center 失去「零依赖、单文件可跑」的特性，收益不抵成本。

【判断】一期只保证**可迁移**，不保证**已支持**：把数据访问收敛到一个明确的方言层，添加 PG/MySQL 时只新增驱动，不改业务代码。

### 3.2 迁移路径

当前 `center/src/db/*.mjs` 直接调用 `node:sqlite`。添加新库时需要处理四类差异：

| 差异点 | SQLite | PostgreSQL | MySQL |
|---|---|---|---|
| 占位符 | `?` | `$1, $2...` | `?` |
| 自增/返回 ID | `lastInsertRowid` | `RETURNING id` | `lastInsertId` |
| JSON 字段 | TEXT + 应用层编解码 | `jsonb`（可查询） | `json` |
| DDL | `CREATE TABLE IF NOT EXISTS` | 同 | 同 |
| 并发模型 | 单写者 | MVCC | MVCC |

【判断】最小改造是引入一个**方言对象**，只暴露数据访问真正用到的操作：

```text
dialect.placeholders(n)     生成占位符
dialect.insertReturning(sql) 包装 RETURNING
dialect.parseJson(text)     统一 JSON 解析
dialect.jsonDbType          JSON 列类型
dialect.begin/commit/rollback
```

`db/*.mjs` 只依赖这个对象，不直接依赖 `node:sqlite`。驱动以可选方式加载：SQLite 用内置模块（零依赖），PG/MySQL 用 `pg` / `mysql2`，**仅在配置选择该类型时才要求安装**。

### 3.3 迁移数据

一期不提供自动迁移工具。需要时按对象导出 JSON（项目、主干条目、需求、决定、任务、提交、评审、变更、影响项、事件），再导入新库；事件表保证顺序与可追溯。

【判断】不要在这个阶段做在线迁移或双写。真有多用户并发需求，先压测 SQLite 的单写者瓶颈，再决定切 PG 的哪一层。

## 4. 部署形态

| 形态 | 适用 | 说明 |
|---|---|---|
| 单机 SQLite | 小团队、内网、试点 | 当前默认；备份 = 复制 db 文件 |
| 单机 + 反向代理 | 团队内多人 | Center 监听 `127.0.0.1`，由 nginx/Caddy 暴露并加 TLS |
| 容器 + PostgreSQL | 多人并发、已有运维 | 驱动可选安装；配置走环境变量 |
